기살 모바일 상담 동선 보완 · 2026-11-15

사용자 요청: 모바일 CTA 겹침 제거, 상담 화면의 기본/셋업 구분 표시, 기존 상담 항목 유지, 미확정 조건 추가 없이 배포.

변경
- Hero 영역을 지난 뒤 고정 상담 바를 표시한다. 본문 상담 버튼이 화면에 들어오면 바를 숨겨 버튼을 가리지 않으며, 버튼이 화면을 벗어나면 다시 표시한다.
- IntersectionObserver를 사용하는 작은 Client Component로 구현. 최초 렌더는 숨김, unmount 시 observer 해제, 숨겨진 바는 접근성 트리·탭 순서에서도 제외. 데스크톱은 기존처럼 고정 바를 표시하지 않는다.
- 검증된 source_plan이 basic/setup인 경우 상담 각 단계와 완료 화면에 관심 과정(기본 과정/스타트 셋업 패키지)을 표시한다.
- 일반·직접·잘못된 URL 유입은 과정 이름을 임의로 지정하지 않는다. 관심 과정은 등록·결제 확정이나 새로운 입력 항목이 아니다.
- 상담 첫 진입 시 최상단으로 이동해 이전 페이지의 스크롤 이동 중 관심 과정 안내를 지나치지 않도록 한다. 단계 이동의 기존 포커스 처리는 유지한다.

보존
상담 필드·필수 여부·선택지·동의·검증·전송 payload·무료/오프라인 선택·단계 이동·GA4 이벤트 및 유입 구분은 유지.
가격·커리큘럼·지원 범위·운영 조건 변경 없음.

검증 기준
모바일 첫 화면 / Hero 이후 / 본문 CTA가 뷰포트 하단에 진입 / 본문 CTA 중간 / CTA를 지난 뒤 / 최상단 복귀 / 리사이즈에서 바 노출 상태를 확인.
기본·셋업·일반 유입의 상담 단계 이동·이전 이동·새로고침과 과정 표시·출처 구분 확인.
실제 신청 없이 모의 RPC 테스트로 완료 화면과 출처 유지 확인.
