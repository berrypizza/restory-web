# 전환 구조 분석

## 1. 고객이 5초 안에 이해할 수 있는 내용

현재 상태: 가구·싱크대·소파를 버리기 전 수리/리폼 가능성을 확인하는 사이트라는 점은 명확합니다.
근거: `app/layout.tsx`, `lib/site-config.ts` hero 문구.
문제: 서비스가 많아 첫 화면에서 어떤 서비스가 대표인지 분산될 수 있습니다.
개선 방향: 핵심 3개 서비스와 사진 상담 CTA를 첫 화면에서 더 강하게 묶기.
관련 페이지 또는 파일: `app/page.tsx`, `lib/site-config.ts`

## 2. 첫 화면에서 알 수 없는 내용

현재 상태: 정확한 가격, 작업 가능 날짜, 사진 몇 장이 필요한지는 저장소 기준 명확하지 않습니다.
근거: 가격/예약 데이터 구조 없음.
문제: 즉시 판단을 원하는 고객이 문의 전 이탈할 수 있음.
개선 방향: "사진 3장: 전체/문제부위/옆면"처럼 안내 고정.
관련 페이지 또는 파일: `app/components/ContactCTA.tsx`

## 3. 대표 서비스 명확성

현재 상태: 싱크대 수리, 싱크대 리폼, 가죽 리폼, 소파 복원으로 분류되어 있습니다.
근거: `lib/site-config.ts`.
문제: 실제 매출 중심 우선순위는 저장소에서 확인 불가.
개선 방향: 문의/매출 기준 1순위 서비스를 첫 화면과 메뉴에서 강조.
관련 페이지 또는 파일: `lib/site-config.ts`

## 4. 서비스 가능 지역

현재 상태: SEO 지역 키워드는 많지만 실제 가능/제한 조건은 분리되어 있지 않습니다.
근거: `lib/seo-regions.ts`.
문제: 거리 긴 문의가 들어올 수 있음.
개선 방향: 1등급/2등급/제한 지역 데이터 추가.
관련 페이지 또는 파일: `lib/seo-regions.ts`

## 5. 가격 또는 예상 범위

현재 상태: 비교 문구는 있으나 구조화 가격표는 확인 불가입니다.
근거: 서비스 JSON 추출 결과 price 확인 불가.
문제: 고객이 가격 비교만 하거나 문의 전 불안해할 수 있음.
개선 방향: "현장별 달라지는 이유"와 "최소 판단 기준"을 같이 노출.
관련 페이지 또는 파일: `lib/site-config.ts`

## 6. 사진 안내

현재 상태: 사진 상담 CTA는 강하지만 필요한 사진 종류는 모든 페이지에서 충분히 구조화되지 않았습니다.
근거: CTA 문구 중심.
문제: 상담 전 추가 질문이 늘어날 수 있음.
개선 방향: 서비스별 필수 사진 체크리스트 추가.
관련 페이지 또는 파일: 서비스 페이지, `ContactCTA`

## 7. 제작 기간과 시공 시간

현재 상태: 분리 데이터 없음.
근거: `03_SERVICES.json`.
문제: 문짝 제작형과 현장 수리형의 기대 시간이 섞일 수 있음.
개선 방향: 제작형/당일형/확인 필요형 구분.
관련 페이지 또는 파일: `lib/site-config.ts`

## 8. UV 하이그로시와 PET 차이

현재 상태: 팁 콘텐츠로 일부 설명됨.
근거: `lib/tips/contents/sink-door-replacement-cost-pet-highgloss.ts`, `why-kitchen-looks-old-glossy-uv-doors.ts`.
문제: 서비스 페이지와 연결 강화 필요.
개선 방향: 싱크대 문짝 페이지에서 비교 표와 실제 사례 연결.
관련 페이지 또는 파일: `app/kitchen/sink-door/page.tsx`, `lib/tips`

## 9~20. 요약 우선순위

현재 상태: 실제 사례와 전후 사진은 강점입니다. 카카오톡 문의 CTA도 반복됩니다.
근거: `lib/case-data.tsx`, `app/components`.
문제: 가격, 작업 시간, 지역 등급, 사진 가이드가 구조화되어 있지 않습니다.
개선 방향: 1순위 사진 가이드, 2순위 가격 범위, 3순위 지역 등급, 4순위 사례별 원인/방법 필드 구조화, 5순위 후기/리뷰 구조화.
관련 페이지 또는 파일: `lib/case-data.tsx`, `lib/site-config.ts`, `app/components/ContactCTA.tsx`
